# Jotis86 Tap

Homebrew formulae for my command-line tools.

## naturgy

A JSON-first CLI for **your own** Naturgy España account: supplies, consumption, readings,
invoices, debt, cases and the virtual battery, over the Área Clientes "Omega" API. Every command
writes JSON to stdout.

```bash
brew install Jotis86/tap/naturgy
naturgy --version
naturgy auth login
naturgy supplies
```

Source: <https://github.com/Jotis86/naturgy_cli> · PyPI: <https://pypi.org/project/naturgy-cli/>

This is an unofficial client of an undocumented API. It is not affiliated with or endorsed by
Naturgy, and you should use it only with your own account.

## Other formulae

`brew install Jotis86/tap/<formula>`, or `brew tap Jotis86/tap` once and then
`brew install <formula>`.
